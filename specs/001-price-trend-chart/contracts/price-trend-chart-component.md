# Contract — `apps/web/src/components/PriceTrendChart.jsx`

取代 `CardDetailPage` 中原有的「市場價格歷史」與「台幣價格趨勢」兩個區塊。

## Props

| Prop | 型別 | 必要 | 說明 |
|---|---|---|---|
| `cardId` | string | 是 | 取得外部市場行情用 |
| `prices` | `PriceSnapshot[]` | 是 | 頁面既有的完整快照陣列。**元件不自行取得快照**（SC-008、不新增 API 呼叫點） |

## 內部狀態

| 狀態 | 說明 |
|---|---|
| `days` | `7 \| 30 \| 90`，預設 7 |
| 外部市場行情快取 | 以映射後的 range 為 key，存於 ref（FR-032） |
| 是否窄螢幕 | 由 `matchMedia('(max-width: 767px)')` 提供（R3） |

## 行為契約

### 區間切換

| # | 規則 | 對應 FR |
|---|---|---|
| B1 | 提供三個區間鈕，標示「7 天／1 個月／3 個月」，實際長度為 7／30／90 天 | FR-010 |
| B2 | 切換不重新載入頁面，資料由既有 `prices` 前端切分 | FR-011 |
| B3 | 窄螢幕時只渲染「7 天／1 個月」兩顆鈕 | FR-024 |
| B4 | 由寬變窄且當前為 90 天 → 自動改為 30 天，不得出現空白或錯誤 | FR-025 |

### 外部市場行情

| # | 規則 | 對應 FR |
|---|---|---|
| B5 | range 映射：`days <= 30` → `month`；`days === 90` → `quarter` | R6 |
| B6 | 命中快取則不發請求；每種粒度整個瀏覽期間最多一次 | FR-032、SC-012 |
| B7 | 取得失敗時圖表照常呈現其餘來源，不顯示錯誤畫面 | FR-016 |
| B8 | 等待期間立即以已有來源繪製，**不顯示載入指示**；到達後直接補入 | FR-033 |

### 圖表呈現

| # | 規則 | 對應 FR |
|---|---|---|
| B9 | 對 `series` 逐一產生 `<Line>`，線數由資料決定 | FR-003 |
| B10 | 每條線同時設定 `stroke`（顏色）與 `strokeDasharray`（線型） | FR-029 |
| B11 | 使用內建 `<Legend />`；已驗證會帶出 `strokeDasharray` | FR-004、FR-030 |
| B12 | `connectNulls` 開啟，缺值日不標示為資料點 | FR-008 |
| B13 | `dot` 依區間決定：`days <= 30` 顯示，`days === 90` 關閉 | FR-013 |
| B14 | `dot` 為函式，依 `__suspicious` 回傳不同形狀 | FR-022 |
| B15 | 橫軸 `interval="preserveStartEnd"`，長區間刻度不重疊 | FR-013 |
| B16 | 縱軸為台幣，加千分位格式化 | FR-001 |
| B17 | 提示顯示該日各 series 的台幣價；`null` 者不列出 | FR-005 |
| B18 | 提示中標示疑似異常，並在有值時顯示外部市場行情成交量 | FR-017、FR-023 |

### 空狀態

| # | 條件 | 呈現 | 對應 FR |
|---|---|---|---|
| B19 | `prices` 為空 | 「尚無價格紀錄」 | FR-018 |
| B20 | `prices` 非空但 `series` 為空（全部無法換算） | 使用者導向訊息，讓訪客理解價格暫時無法以台幣呈現、非自身操作有誤。**不得包含維運指令或內部細節** | FR-019、SC-013 |
| B21 | 僅單一天資料 | 正常渲染，不崩潰 | FR-020 |

## 禁止事項

- 不得在元件內直接呼叫 `fetch`；一律經 `lib/api.js`（專案守則）
- 不得在前台輸出維運指令、系統內部路徑或執行指令（FR-019、SC-013）
- 不得為外部市場行情顯示 spinner 或骨架屏（FR-033）
- 不得對外部市場行情缺漏的日期做補值或插值（FR-031）
